# Sudoku

A calm, colourful Sudoku for kids and families, built with Expo and React Native. One codebase runs in the browser, on iPhone and iPad, and on Android.

Live web version: https://kamalsoft.github.io/sudoku/

Developer: Kamalesh

## Features

- **Eight levels:** Beginner, Easy, Medium, Hard, Expert, Master, Evil and Genius. Puzzles are generated with a unique solution.
- **Daily puzzle:** the same puzzle for everyone on the same day.
- **Named challenges:** fourteen fixed combinations of level, time limit, mistake limit and hint limit, named after space and sky references (Sunrise, Lunar Walk, Comet Dash, Orion’s Belt, Nebula, Pulsar, Quasar, Supernova, Event Horizon and more).
- **Help when stuck:** pencil notes, auto-notes, hints, undo and redo, and red marks for wrong or repeated digits.
- **Stars and badges:** each qualified win earns 1 to 3 stars. Badges unlock from your history, including Challenger (win a named challenge) and Mission Control (win every named challenge).
- **Level up:** each level opens after three qualified wins on the one before (optional).
- **Casual play:** with no mistake limit, play stops at Medium and five casual wins a day. Set a mistake limit to open every level.
- **Kid-safe mode:** no mistake limits and no timers, with encouraging messages written for children.
- **Parent lock:** a simple sum must be answered before Settings or the parent summary opens.
- **Profiles:** each child has their own games, stats, badges and settings on the same device.
- **Stats and summary:** recent games (with Replay), best times, a by-level table and a weekly parent summary.
- **Comfort:** large digits, colour-blind markers, reduced motion, and skins in three categories (Classic, Dark and Kids).
- **Languages:** English, Español and Français.
- **Installable:** add the web version to your home screen, or install it on a phone.
- **No ads, no accounts, no tracking.**

## Getting started

```bash
git clone https://github.com/kamalsoft/sudoku.git
cd sudoku
npm ci
npx expo start
```

Then press `w` to open the web version, or scan the QR code with Expo Go. Expo Go only includes its bundled native modules. For a build with the full set, use a development build (see below).

## Building and deploying

### Web (GitHub Pages)

`.github/workflows/deploy-web.yml` runs on every push to `master`:

1. **check:** typecheck, lint and tests.
2. **deploy:** `expo export --platform web`, then publish `dist/` to GitHub Pages.

The app is served from `/sudoku` in production (`experiments.baseUrl` in `app.json`). In development it runs from the root. The web build also includes a service worker and a web app manifest, both only in production, so the app can work offline after the first visit.

### Phones (EAS)

Native builds run in the cloud with EAS. Profiles are in `eas.json`:

```bash
npx eas-cli@latest build --profile development --platform ios
npx eas-cli@latest build --profile preview --platform android
npx eas-cli@latest build --profile production --platform all
npx eas-cli@latest submit --profile production
```

Over-the-air updates ship with `eas update`. Building for the stores needs your own Apple and Google developer accounts. Bundle identifiers are set in `app.json`: `com.kamalsoft.sudoku`.

The `ios/` and `android/` folders are generated by Expo. Do not edit them by hand. Change native settings in `app.json` or with config plugins.

### How the game works

- **Puzzles:** `src/sudoku/engine.ts` generates a full solution with a seeded random generator, then removes clues while the puzzle keeps exactly one solution. The daily puzzle uses a seed built from the date.
- **Levels:** `src/sudoku/levels.ts` lists the levels and their clue targets.
- **Qualified wins:** a win counts as qualified unless hints filled every empty square. Only qualified wins earn stars, badges, level progress and best times.
- **Casual play:** no mistake limit, Kid-safe mode included. Rules are in `src/sudoku/rules.ts`.
- **Data:** saved games and history are in a local SQLite database. The schema version is tracked with `PRAGMA user_version` in `src/db/database.ts`.

## Level logic

This section explains how a level becomes a puzzle, how levels unlock, and how the casual and challenge rules are applied in code.

### The eight levels

`src/sudoku/levels.ts` is the single list of levels, in order from gentlest to hardest. Each level has a clue target: the number of given digits the generator aims for.

| Level | Clue target | Unlocks after (with Level up) |
|---|---|---|
| Beginner | 46 | start |
| Easy | 42 | 3 qualified Beginner wins |
| Medium | 34 | 3 qualified Easy wins |
| Hard | 28 | 3 qualified Medium wins |
| Expert | 24 | 3 qualified Hard wins |
| Master | 22 | 3 qualified Expert wins |
| Evil | 20 | 3 qualified Master wins |
| Genius | 18 | 3 qualified Evil wins |

A lower target means fewer clues, so the puzzle is harder.

### Generating a puzzle

`generatePuzzle(difficulty, rng)` in `src/sudoku/engine.ts` works in three steps:

1. **Full solution:** `randomSolution` fills an empty grid with backtracking, trying digits in random order.
2. **Carving:** `carve` removes clues in 180-degree symmetric pairs. A removal is kept only if `countSolutions` still finds exactly one solution. Carving stops once the clue count reaches the target.
3. **Retries:** if carving stops above the target, the generator tries again with a new solution, up to 20 times, and keeps the sparsest puzzle it found.

The daily puzzle is the same for everyone on a given day. `dailySeed` turns the date into a seed, and `createRng` (a seeded generator) makes the same choices each time. Other games use `Math.random`.

**Known limit:** greedy symmetric carving stalls near 23 to 26 clues. So Expert, Master, Evil and Genius can land a few clues above their targets, and the sparsest levels play close to each other. The test in `src/sudoku/engine.test.ts` allows a slack of 8 clues for those levels. Upgrading the removal order would close this gap.

### Unlocking levels (Level up)

`unlockedLevels(games, levelUp)` in `src/sudoku/progress.ts` decides which levels are open:

- **Level up off:** every level is open.
- **Level up on:** Beginner is open. Each next level opens when the player has at least `WINS_TO_UNLOCK` (3) wins on the level before it. Only qualified wins count, and daily games are not counted.

`nextLevelProgress` uses the same rule to show how many more wins the next locked level needs.

### Casual play

Casual play means there is no mistake limit. The check is `isCasual(kidSafe, mistakeLimit)` in `src/sudoku/rules.ts`, which is true when `guardedMistakeLimit` returns `null`. Kid-safe mode always counts as casual, because it turns mistake limits off.

Casual play is limited in two ways:

- **Level cap:** casual games stop at `CASUAL_MAX_LEVEL` (Medium). Higher levels are open only with a mistake limit.
- **Daily cap:** after `CASUAL_DAILY_WINS` (5) casual wins in a day, no new casual games can be started. `casualWinsOn` counts the won games with `casual` set for today.

`levelAllowed(level, casual, casualWins)` applies both rules. The store's `allowedNow` supplies the current settings and games. The daily puzzle is exempt from the cap, but its win still counts towards it.

**Known limit:** the level and cap check runs when a game is started from the menu. A saved game restored at launch skips it, so reloading the app after a casual win starts a new game at the saved level without the check.

### Named challenges

`src/challenges.ts` holds the fixed challenges. Each one sets a level, a clock (`minutes`, or `null` for no clock), a mistake limit and a hint limit. Starting a challenge calls `startChallenge` in `src/sudoku/store.ts`, which applies those values to that game only:

- `gameLimits` uses the challenge's mistake and hint limits in place of the player's settings.
- The challenge clock replaces the player's time limit. The player's saved choice is not changed.
- Every challenge has a mistake limit, so it is never casual. Kid-safe mode still turns the limits off, and a Kid-safe challenge is then treated as casual.

### Scoring and what counts

- **Qualified win:** `hintsQualify(puzzle, hints)` is true unless hints filled every empty square. Stars, badges, level progress and best times use qualified wins only.
- **Stars:** `starsFor(mistakes, hints)` starts at 3 and loses one for each mistake or hint, never going below 1.
- **Mistakes:** a digit that differs from the solution counts as a mistake. When the mistake limit is reached, the game ends.
- **Clocks:** when the time runs out, the game ends. The top bar shows the time left.

## Testing

Pure game logic has unit tests next to the code, in `src/sudoku/*.test.ts` and `src/challenges.test.ts`. Run them with `npm test`. Tests cover the solver, puzzle generation, rules, progress, stats, persistence and the motivation messages.

The screens are checked by hand in a browser at phone and desktop widths.

## Data and privacy

Everything stays on the device: games, stats, profiles and settings. The app sends nothing to a server. The privacy policy and terms are in the app under Menu → Help.

## Languages

Interface strings live in `src/i18n.ts`. English is the reference. Spanish and French are partial tables, and any missing string falls back to English. To add a string, add it to the English table first, then to the others.

## FAQ

**Is my progress saved between visits?** Yes, on this device or in this browser. Clearing the browser’s site data removes it.

**Why can’t I play Hard or Evil yet?** With Level up on, each level opens after three wins on the one before. Casual play stops at Medium and five casual wins a day. Set a mistake limit in Settings to open every level.

**What is casual play?** No mistake limit. Mistakes are counted but never end a game. It is the default. Kid-safe mode also plays without limits.

**What do hints do to a win?** A win counts as qualified unless hints filled every empty square. Other wins still count as wins, but they earn no stars, badges, level progress or best times.

**How do I clear stats for one player?** Open Settings, then Players, and choose Clear stats. Saved settings stay.

**Does the app have ads or tracking?** No.

More questions are in the About screen of the app.

## Known limits

- The generator reaches the clue targets for the lower levels. For Expert, Master, Evil and Genius it can land a few clues above target, so those levels can be a little easier than their names suggest.
- Sound clips are synthesised and have not been checked by ear on a device.
- Native builds, store listings and the iOS build still need the developer accounts. Offline use on phones is not verified.
- Spanish and French legal text needs a native review.
